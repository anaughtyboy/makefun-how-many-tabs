An entry for the make.fun bounty [How Many Tabs Do You Have Open?](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d).

The answer: **137** — the honest count of browser tabs open on the day this entry was built. Not a round number, not a guess: a tab hoarder's real count, counted tab by tab.

`main.ts` writes exactly those three digits to `entry.txt` — no words, no punctuation, no trailing newline.
